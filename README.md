<h1 align="center">🌦️ Weather App</h1>

<p align="center">
A simple and clean weather application built with HTML, CSS, and JavaScript that fetches real-time weather data using the <a href="https://openweathermap.org/api" target="_blank">OpenWeatherMap API</a>.
</p>

<hr />

<h2>🚀 Features</h2>
<ul>
  <li>🌤️ Get real-time weather information by searching a city</li>
  <li>📅 Shows the current date and weather condition</li>
  <li>🌡️ Displays temperature, humidity, and wind speed</li>
  <li>📊 5-day forecast with weather icons</li>
  <li>⚙️ Clean and responsive UI built with pure HTML, CSS, and JS</li>
</ul>

<h2>🛠️ Tech Stack</h2>
<ul>
  <li><strong>Frontend:</strong> HTML5, CSS3, JavaScript</li>
  <li><strong>API:</strong> OpenWeatherMap API</li>
</ul>

<h2>📁 Project Structure</h2>
<pre>
├── index.html         # Main HTML file
├── style.css          # Styling
├── script.js          # Main JS logic for API calls and UI updates
├── assets/            # Weather icons and images
</pre>

<h2>⚡ How to Run</h2>
<ol>
  <li>Clone the repository:</li>
  <pre>git clone &lt;repository-url&gt;</pre>

  <li>Open <code>index.html</code> in your browser</li>

  <li>Search for a city and get the weather updates instantly!</li>
</ol>

<h2>🔑 API Configuration</h2>
<p>Replace the <code>apiKey</code> variable in <code>script.js</code> with your own OpenWeatherMap API key:</p>

<pre>
const apiKey = "YOUR_API_KEY_HERE";
</pre>

<h2>🛡️ Example API Response:</h2>
<p>Check the console logs in <code>script.js</code> to view the API responses for weather and forecast data.</p>
